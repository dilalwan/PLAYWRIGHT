# PLAYWRIGHT

A collection of small JavaScript examples and exercises arranged by chapter. Each chapter folder groups related topics and contains runnable scripts for hands-on learning.

## Overview

This repo is a study playground for JavaScript basics. Files are intentionally small and focused so you can run and modify them with `node`.

## How to run examples

Install Node.js (v14+) and run any example with:

```bash
node <path-to-file>
```

Example:

```bash
node 01_chapter_Javascript/01_Hello_World.js
```

## Contributing guidelines

- Add focused examples to the relevant chapter. Keep files small (one concept per file).
- Name files with a numeric prefix to keep logical ordering (e.g. `01_`, `02_`).
- Add short comments at the top of each file explaining its purpose.

If you'd like, I can:
- enumerate and include file contents or sample outputs inline,
- add a table of contents with links to each file, or
