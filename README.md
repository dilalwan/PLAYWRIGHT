# PLAYWRIGHT

A small collection of JavaScript example files and exercises organized by chapter.

## Overview

This repository contains a set of learning examples organized into chapter folders. Each folder contains small JavaScript files demonstrating language features and patterns.

## Structure

- `01_chapter_Javascript/` — Hello world and basic examples
- `02_chapter_Javascript/` — Let/const and related examples
- `03_chapter_Identifier/`
- `04_chapter_Literal/`
- `05_chapter_Operator/`
- `06_chapter_Statement/`
- `07_chapter_Switch/`
- `08_chapter_UserInputs/`
- `09_chapter_Loops/`
- `10_chapter_Arrays/`
- `11_chapter_Functions/`
- `12_chapter_Fn_Closure/`
- `13_chapter_Strings/`

## How to run

You need Node.js installed to run the example scripts. Run a file with:

```bash
node 01_chapter_Javascript/01_Hello_World.js
```

Replace the path with any file you want to run.

## Contributing

- Add new example files under the appropriate chapter folder.
- Keep filenames descriptive and small.
